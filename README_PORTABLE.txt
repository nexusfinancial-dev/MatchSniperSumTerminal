[ARABIC - دليل الاستخدام السريع]
هذا البرنامج عبارة عن نسخة تنفيذية محمولة (Standalone Portable .exe) تعمل على أي جهاز كمبيوتر بنظام Windows (Windows 10 / 11 64-bit) دون الحاجة لتثبيت بايثون (Python) أو أي برامج وسيطة.

طريقة التشغيل:
1. انقر نقراً مزدوجاً فوق "MatchSniperTerminal.exe" أو "START_TERMINAL.bat".
2. ستفتح نافذة الأوامر لبدء تشغيل المحرك على المنفذ 8565، وسيفتح المتصفح تلقائياً على الرابط:
   http://localhost:8565
3. لإدخال أو تعديل توكن الحساب وتفاصيل Deriv API:
   - اضغط على زر "🔑 CREDENTIALS" في الشريط العلوي للواجهة.
   - أدخل توكن الحساب التجريبي أو الحقيقي واضغط "Save & Apply".
   - أو يمكنك تعديل ملف "credentials.json" الموجود بجوار ملف التشغيل مباشرة.
4. جميع سجلات التداول والصفقات تحفظ تلقائياً في ملف:
   match_sniper_trades.csv

[ENGLISH - QUICK START GUIDE]
This is a standalone portable Windows binary (.exe) that runs on any modern Windows OS (Windows 10 / 11 64-bit) without requiring Python or any external runtime dependencies.

How to Run:
1. Double-click "MatchSniperTerminal.exe" or "START_TERMINAL.bat".
2. The terminal engine will start on Port 8565 and your default browser will automatically open:
   http://localhost:8565
3. Managing Deriv API Credentials:
   - Click the "🔑 CREDENTIALS" button in the dashboard top navigation bar.
   - Enter your Demo or Real Account ID and API Token, then click "Save & Apply".
   - Alternatively, edit the "credentials.json" file located in the same directory.
4. Trade logs and audit history are automatically saved to:
   match_sniper_trades.csv

Port: 8565
Local URL: http://localhost:8565
Network / LAN URL: http://<YOUR_IP>:8565
